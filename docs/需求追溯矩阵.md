# 可信 RAG 银行业监管问答系统：需求追溯矩阵

## 1. 文档定位

本文档把产品需求、GitHub Issue、实现模块、自动化测试、提交和验收状态连接起来，回答“为什么做、在哪里实现、如何证明完成”。

状态基于 2026-09-02 对当前仓库和 GitHub Issue 的核对。Issue 是任务与功能规格入口；本文档不复制 Issue 正文，也不替代 Git 历史和测试结果。

产品需求编号见[产品需求说明](产品需求说明.md)，验收用例编号见[验收方案](验收方案.md)。

## 2. 总体追溯关系

```mermaid
flowchart LR
    A[产品需求 PR] --> B[GitHub Issue]
    B --> C[实现模块]
    C --> D[自动化测试]
    D --> E[Git Commit]
    E --> F[Issue 验收与关闭]
    F --> G[产品/评测/验收文档]
```
